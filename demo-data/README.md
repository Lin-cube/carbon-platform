## 一、数据构成

| 项 | 内容 |
|---|---|
| 建筑 | 3 栋真实建筑：`Eagle_office_Dallas`（办公楼）、`Rat_education_Keith`（教学楼）、`Hog_office_Sydney`（办公楼） |

**为什么用已有建筑**：异常检测需要「同星期几同小时」的历史基线。
新建筑没有历史 → 基线为空 → 全部标记为「未评估」，反而演示不出异常。

## 四、导入建议参数

```json
{
  "cleanRules": {
    "trimString": true,
    "missingStrategy": "drop",
    "dropNegative": true,
    "dedupStrategy": "byBuildingTime",
    "electricityUnit": "kwh",
    "unitConsistencyCheck": true
  }
}
```

界面操作：数据导入 → 上传本文件 → AI 会自动映射 8/8 字段 → 清洗规则勾选
「缺失剔除 / 负值剔除 / 按建筑时间去重 / 单位一致性校验」→ 预览 → 导入。

## 六、已知限制

- **平均 COP 为空**：本数据集没有冷量计量字段（COP 在原数据中属仿真字段），
  故该区间「平均 COP」显示 `--`。这是如实反映，不是 bug。
- 时间格式异常行会被解析器兼容并正常入库；若要演示「失败行」，
  可把某行时间改成 `2017-13-45` 这类非法值。
