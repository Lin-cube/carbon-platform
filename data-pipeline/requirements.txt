# ⚠️ macOS 环境注意事项（本项目实测踩坑）：
#   不要用 DSH 内置 Python 创建 venv。内置 Python 由特定 Team ID 签名，
#   而 pypi/镜像安装的 C 扩展（numpy/pyarrow 的 .so）签名不同，
#   macOS 会拒绝加载，报 "different Team IDs"。
#   正确做法：用 Homebrew Python 创建项目 venv：
#     /opt/homebrew/bin/python3 -m venv .venv
#
# ⚠️ 网络：pypi.org 在本机不可达（15s 超时），必须用国内镜像。
#   项目内已提供 data-pipeline/pip.conf（清华源），用法：
#     export PIP_CONFIG_FILE=$PWD/data-pipeline/pip.conf && pip install ...
