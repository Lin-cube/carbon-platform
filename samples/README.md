## 两个模板分别是什么

| 模板 | 作用 |
|---|---|
| **能耗数据模板** | 每行 = 一栋楼 + 一个时刻的读数。导入后进入 `fact_energy_hourly`，驱动看板、查询、分析、异常检测、AI 诊断。**必须含建筑编号 + 监测时间。** |
| **建筑台账模板** | 建筑的基础档案（面积、类型等），不带时间维度。**当前版本仅支持"识别"，不支持自动落库**，模板只作字段格式参考。 |

## 单位与格式

- 电量统一 **kWh**（MWh 请先换算）
- 时间：`2017-08-01 00:00:00` 或 `2017-08-01 00:00`
- 编码：UTF-8 或 GBK 均可（本文件带 BOM，Excel 打开不乱码）
- 单次上限：20 万行 / 100MB

`2017-08` 那份（前一年数据完整，基线正常）。
